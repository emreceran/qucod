Yüzbaşıgil Prefabrik: we made project-based production visible in Odoo

In precast production every project has different dimensions and different parts. We brought that complexity into a single flow with a custom production system built on Odoo 18 — and took it live.

Yüzbaşıgil manufactures precast buildings — every order is a project of its own, with different dimensions and parts. We brought this project-based production into a single flow with a system built on Odoo.

From order to production, from shipping to on-site installation, the whole process is in one place, and management sees it live. Real production tracking instead of scattered Excel files and paper. The system is in active use today.
